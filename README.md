# 生涯决策工具 · 选科罗盘 + 多元智能

面向新高考「3+1+2」的生涯决策工具，单文件纯静态网页，无需构建、无需后端。

## 两个模块

1. **① 选科罗盘**：给六门学科打分（-5 ~ +5），结合学术深度 / 就业稳定 / 生涯方向三项偏好，
   把 12 种合法组合全部算一遍，按「匹配度 × 权重 + 专业覆盖率 × 比例」排序。
2. **② 多元智能**：45 题、九个维度的自我报告量表（加德纳多元智能理论改编），
   输出九维雷达图、优势智能、结构均衡度，并与选科结果做交叉分析，生成生涯画像。

## 交叉分析

选科页生成排行榜后，切到多元智能页会自动带入选科结果；也可以点「导入选科结果并交叉分析」手动导入。
交叉分析会给出：核心结论、互相印证 / 需要留意的张力、九维智能 → 六科适配度对照表、职业方向与专业建议。

## 部署

纯静态，直接托管即可：

- 入口：`index.html`
- `404.html`：与入口同内容，保证任意路径都能回到工具
- `.nojekyll`：跳过 Jekyll 处理
- `CNAME`：自定义域名（`feipsy.com.cn`）

GitHub Pages 设置：Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
